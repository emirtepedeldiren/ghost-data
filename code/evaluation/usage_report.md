## How the final run used the models

- The submitted `output.csv` (518 rows) comes from the frozen run `python3 code/main.py` with `code/config/frozen_v1.toml` (models: intent `gemini-2.5-flash`, screenshots `gemini-3.5-flash-lite`, provider `gemini`).
- **The final run was served entirely from the response cache: 0 live API calls** (D26, free tier). The run is cache-only: a cache miss aborts it, and no API key is needed.
- The cached responses were produced by **16 original API calls on 2026-10-24 between 2026-10-24T13:58:20Z and 2026-10-24T14:01:34Z** (call-log timestamps, UTC). The usage below is the usage of those calls, which is what the final output costs.
- The LLM is used in exactly two places: request intent (5 batched calls classify the 398 unique request texts of the eval and sample files, 80 per call) and screenshot transcription (1 call per PNG, 11 PNGs). Everything else is deterministic code.
- Average tokens and cost per request divide the totals by the 518 eval requests. The intent batches also cover the 32 sample texts; they are not split out.
